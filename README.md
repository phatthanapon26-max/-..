# ระบบจัดการลูกหนี้ โรงน้ำดื่ม เฟรชชี่ วอเตอร์

ระบบจัดการลูกหนี้ สำหรับโรงน้ำดื่ม เชื่อมต่อ **Google Sheets** เป็นฐานข้อมูลหลักแบบ real time รันบน **Vercel** ได้ ไม่ใช้ Google Apps Script

## รหัสเข้าสู่ระบบ (ครั้งแรก)
- **แอดมิน:** `7716` (เข้าแล้วไปเพิ่มพนักงาน / ตั้งค่าฐานข้อมูล / ตั้งค่าระบบที่หน้าการตั้งค่า)
- **พนักงานตัวอย่าง:** `1001` (สมชาย ใจดี), `1002` (สมศรี มีแสน) — แอดมินสามารถเพิ่ม/แก้ไขได้ที่หน้า จัดการพนักงาน

## วิธีรันบน Vercel
1. อัปโหลดโฟลเดอร์ทั้งหมดขึ้น GitHub (หรือใช้ `vercel deploy` ผ่าน CLI)
2. ที่ Vercel → Add New → Project → เลือก repo → Deploy (ไม่ต้องตั้งค่าอะไรเพิ่ม)
3. ผูกโดเมนของตัวเองที่ Settings → Domains
4. เปิดเว็บ → ล็อกอินด้วย `7716` → เข้า **การตั้งค่า → ฐานข้อมูล** ใส่ลิงก์ Google Sheets, Sheet ID, API Key, Service Account Email, Private Key → บันทึก

## วิธีตั้งค่า Google Sheets (ไม่ใช้ Apps Script)
1. สร้าง Google Sheet ใหม่ สร้างแท็บ (tab) ตามนี้: `customers`, `debtors`, `cashsales`, `products`, `employees`, `audit`, `approvals` (แถวแรกเป็นชื่อคอลัมน์)
2. ไป Google Cloud Console → สร้าง Service Account → สร้าง Key ประเภท JSON → คัด `client_email` และ `private_key`
3. กลับมาที่ Google Sheet → แชร์ให้ `client_email` เป็น **Editor**
4. ใส่ข้อมูลทั้งหมดในหน้าการตั้งค่า → เลือกโหมด `Google Sheets` → บันทึก
5. ระบบจะอ่าน/เขียนข้อมูลผ่าน `api/sheets.js` ทุกครั้ง และ polling real time ทุก 5–15 วินาที

## วิธีตั้งค่าอีเมลแจ้งเตือน
- ที่ การตั้งค่า → อีเมลแจ้งเตือน → เปิดใช้งาน → ใส่อีเมลแอดมิน → เลือกผู้ให้บริการ (Resend API แนะนำ หรือ SMTP) → ใส่ API Key → ติ๊กประเภทการแจ้งเตือน (ล็อกอิน / ออกระบบ / เพิ่มลูกหนี้ / คำขอกลับไปค้าง)
- ฟังก์ชันส่งอีเมลอยู่ที่ `api/email.js`

## โครงสร้างไฟล์
- `index.html` — หน้าแอป (UI, ธีมน้ำเงินกรมท่า+ทอง, สไตล์พิมพ์ A4)
- `app.js` — ตรรกะทั้งหมด (ล็อกอิน, สิทธิ์, ทุกหน้า, realtime, พิมพ์/อีเมล, ป้องกันแคปหน้าจอ)
- `api/sheets.js` — อ่าน/เขียน Google Sheets
- `api/email.js` — ส่งอีเมล (Resend / SMTP)
- `package.json`, `vercel.json` — config สำหรับ Vercel

## คุณสมบัติหลัก
- แยกลูกหนี้ค้างชำระ / รายการจ่ายแล้ว อัตโนมัติ (แม้อยู่ใน sheet เดียวกัน)
- แยกข้อมูลบ้านนาไฮ (โทนฟ้า) / บ้านอื่น ๆ (โทนส้ม) ไม่ปนกัน
- แสดงลูกหนี้แบบ **1 คน 1 ตาราง** พร้อมสรุปยอดท้ายตาราง
- พนักงานเห็นเฉพาะข้อมูลของตนเอง แอดมินกำหนดสิทธิ์แต่ละหน้าได้
- พนักงานแก้ไขลูกค้าจ่ายสดได้ภายใน 2 นาที หลังจากนั้นล็อก แอดมินแก้ได้ตลอด มีประวัติการแก้ไข
- พนักงานขอยกเลิกกลับไปค้างต้องกรอกเหตุผล → แอดมินอนุมัติ (ส่งอีเมลแจ้ง)
- ปริ้นรายงาน A4 กึ่งกลาง เลขที่เอกสารไม่ซ้ำ (ตัวย่อ 3 ตัว + วันเดือนปี + 001) มีช่องเซ็นชื่อ 4 ตำแหน่ง
- ป้องกันแคปหน้าจอ / เปิดซ้อนหน้าจอ (เบลอ + เตือน)
- รองรับข้อมูล 600–1,000 บรรทัด ใช้งานระยะยาว

## หมายเหตุ
- หากยังไม่ตั้งค่า Google Sheets ระบบจะทำงานใน **โหมดสาธิต** บันทึกข้อมูลในเบราว์เซอร์ (localStorage) สามารถสำรองเป็น JSON ได้ที่ การตั้งค่า → ระบบ/ข้อมูล
- ข้อมูลตัวอย่างในโหมดสาธิตเป็นข้อมูลสมมติเพื่อสาธิตการทำงานเท่านั้น
